# 工作区与会话

先打开存放论文、代码或数据的目录，再为当前目标新建会话。工作区决定助手从哪里读文件、查看 Git 和运行命令。回到同一个会话可以接着看此前的消息和结果。

## 认识当前布局

- 在**左侧边栏**找工作区、会话和扩展导航。展开后可打开协作项目、**我的工作**和**收件箱**，底部是账户、云端状态、用量和设置。
- 在**中间会话区**输入任务，查看回复和工具调用。
- 在**最右侧纵向工具栏**打开 **文件** 等面板。未显示的工具先到 **更多工具** 查找。可用工具取决于客户端已安装和启用的功能。
- 拖动边缘可调整面板宽度。支持停靠的页面可以移到左侧、右侧、底部或主区域。会话右侧面板可按功能支持情况拆分或切换内容，用前进和后退查看页面。

## 打开工作区

1. 打开顶部的 **工作区位置** 菜单，选择 **本地工作区** 或已配置且可用的远端目标。
2. 选中论文、代码或数据所在目录。左侧边栏会显示该项目名称和工作区路径。
3. 为新目标创建会话，新会话会出现在对应项目下。继续原有任务时，从侧栏打开已有会话。

![SciForge 新建会话界面](/img/docs/quickstart/quickstart-new-session.jpg)
*选好工作区后，确认新会话出现在对应项目下。*

## 加入文件：选择、拖放、粘贴或引用

### 引用工作区里的文件

在最右侧工具栏打开 **文件**，找到并引用目标文件。也可以在输入区输入 `@` 搜索文件。路径有空格时，写成 `@"目录/文件名"`。输入框上方的附件托盘会出现带文件名和路径的条目。只读演示可以使用这种方式，不会向工作区复制新文件。

![右侧纵向工具栏的文件按钮和打开的工作区文件面板](/img/docs/guides/workspace-files-v0218-zh.png)
*从最右侧纵向工具栏点 **文件**。示例工作区的文件树在旁边展开。*

### 导入工作区外的文件

点输入区的 **添加文件**，也可把受支持的文件拖进输入区，或粘贴剪贴板中的文件、图片。普通文本会直接进入输入框。导入成功后，附件托盘出现文件条目，文件副本保存在工作区的会话附件目录。PDF、图片、科学数据和网页文档有各自的类型与大小要求，导入报错时按提示缩小文件或改用支持的格式。

### 发送前后各检查一次

1. **发送前**，输入框上方的**附件托盘**列出待发送文件的类型、路径和显示的大小。支持预览的条目可点击打开内容。选错的条目可从托盘点 **移除附件** 或 **移除文件引用** 取消发送。已导入的副本仍留在会话附件目录，需要清理时从 **文件** 面板打开该目录再删除。
2. **发送后**，用户消息下方的**已发送文件标签**只表示对应文件已随消息发送。点标签可只读预览该文件。要核查助手是否真正读取并使用了附件内容，可让回复指出文件名及引用的页码、行号或原文短句，再点开附件对照。分析图片时，使用支持图片输入的模型。

![发送前，示例文件出现在输入框上方的附件托盘](/img/docs/guides/workspace-attachment-before-v0218-zh.png)
*发送前，`sample-notes.md` 在输入框上方的 **附件** 托盘里。*

![发送后，用户消息下方显示示例文件标签](/img/docs/guides/workspace-attachment-after-v0218-zh.png)
*发送后，`sample-notes.md` 的标签出现在这条消息下方。点标签可预览文件。*

## 管理会话与审查变更

在侧边栏点会话继续工作，或使用搜索找到历史。暂时用不到的会话可归档，之后按需恢复。删除前，把重要结果另存到工作区或科研记录。

审阅本次改动时，有兼容插件的会话可用 [Change Inspector](../features/change-inspector.md) 检查已记录的文件变更。要查看整个工作区，再运行 `git status --short`。切换会话或关闭面板后，磁盘上的更改仍会保留。

第一次给助手任务时，可以这样写：

> 请读当前工作区的 README、依赖配置和程序入口。告诉我怎样运行和测试，指出还缺哪些信息。本次先做只读检查。
