# 功能状态与限制

本轮按 **2026-11-06 · 主线 `3f6b0c3`**核对实现。下表不把此前的真实案例自动升级为最新版本的跨平台验收；安装包和市场发布状态须另查。[版本与兼容性](./version-and-compatibility.md)说明这些基线的关系。

| 能力 | 本轮状态 | 当前范围与限制 |
| --- | --- | --- |
| 工作区、会话与工作台布局 | 当前实现已核对 | 右侧纵向工具栏、侧栏账户区及面板布局按最新实现说明；历史截图可能使用旧布局。 |
| Codex / Claude Code | 当前入口与配置已核对 | 显式选择 Runtime；模型、登录、文件和工具权限各自配置，不把不同执行者当成静默回退。 |
| DSH Runtime | 当前实现已核对 | 长任务使用空闲超时，持续同会话进度可续期；连接检查和操作确认分别有时间限制。 |
| 附件与发送后文件引用 | 当前实现已核对 | 选择、拖拽、粘贴进入附件托盘；发送后保留文件引用。文件引用不等于每个 Runtime 都收到嵌入二进制。 |
| 文本、代码与其他文件预览 | 当前实现已核对 | 能否编辑取决于格式、是否截断和写回通道；只读原因应在界面显示。 |
| 本地账户、云端设备与用量 | 当前实现已核对 | 本地账户删除不等于删除云端账户或用户文件；云端与模型供应商的身份分开管理。 |
| [团队协作](../features/collaboration.md) | 需要可用服务、角色与任务授权 | 看板、成员、需求、共享文件、项目信息入口；共享文件来自任务交付，当前不提供直接上传。历史 [Pasilla 案例](../cases/pasilla-collaboration.md)保留原验证范围。 |
| [Biology Workbench 预览](../features/life-science-preview.md) | 内置实现已核对 | 大文件可能只显示摘要；分子选区修改后请重新打开核对。 |
| [Scientific Figures](../features/scientific-plotting.md) | 当前实现 MVP.11；历史本地验收 MVP.10 | 冻结数据/代码、真实 Python、分析产物、分页、恢复和环境重建文件；MVP.10 macOS arm64 + DSH 证据保留，未据此声明 MVP.11 全平台或公共市场发布。R 未实现。 |
| [Anchored Comments](../features/anchored-comments.md) | 独立插件 | 捕获和外部反馈需对应宿主能力；删除和提交反馈有明确审批。 |
| [Change Inspector](../features/change-inspector.md) | 独立只读插件 | 让 Agent 列出本次会话的文件差异，过长时分页查看；旧变更面板已移除。 |
| 产物版本、检查点、Evidence / Project DAG、档案 | 条件可用，按具体包核对 | 内置功能可按各页使用；可选 Evidence / Project DAG 插件尚不能替代内置功能。 |
| 定时任务与 Create Loop | 需要应用运行和执行环境 | 任务触发、审批及重启边界按各页说明；不是系统级无人值守服务保证。 |
| 插件市场、Skills、MCP | 条件可用 | 市场读取失败、暂无可安装包和检索为空分别处理；源码、签名包与公开市场上架分开。 |
| Dataset API / Scientific Compute / 旧 Visual Review | 已退出当前独立功能形态 | 旧链接保留迁移说明，不继续提供旧操作入口。 |
| Remote SSH 管理 | 内部补充 | 公开站不提供 VPN、SSH 目标登记与服务端操作步骤。 |
| 虚拟细胞模型、Slurm/PBS/Kubernetes 调度 | 不作为内置能力承诺 | 用户可在授权的外部环境中接入；教程不是模型或调度服务交付。 |

## 如何理解验证状态

源码和契约核对说明实现路径存在；自动化测试说明其覆盖场景通过；真实操作或安装包验收则必须给出版本、平台和日期。三者不能互相替代。本轮文档构建通过也不意味着所有客户端功能已重新验证。

提交问题时附上客户端与插件版本、系统、入口、复现步骤和脱敏截图。历史案例内容与最新界面不一致时，先按版本页判断，再报告正文中的具体差异。
