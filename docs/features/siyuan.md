# 思源笔记

在 SciForge 打开自己的思源服务，查实验笔记、补写记录，或把会话结果存到指定文档。

## 打开方式

1. 准备一个可访问的 HTTP/HTTPS 思源服务。可以用自己部署或订阅的服务器模式服务。需要认证时，提前准备 API Token。
2. 从左侧栏点 **思源笔记**（部分构建显示为 **云服务**），在页面 **设置** 填 **服务地址** 并点 **保存设置**。留空时使用安装配置的默认地址。服务需要认证时，在 **设置** 填 **API 令牌**（API Token），或在启动环境设置 `SIYUAN_API_TOKEN`。页面设置的 Token 优先，并存入应用加密存储。
3. 页面加载出思源编辑器后，打开目标笔记本和文档。也可在 **设置** 点 **测试已保存的连接**，看到连接正常提示后再开始编辑。报错时点 **重试**，或回 **设置** 检查地址和凭据。

编辑器默认在会话右侧。可以从页头移到左侧、底部或主区域，再调整大小。位置和大小保存在本机。

## 打开已有笔记

从左侧栏打开 **思源笔记**，在编辑器里选目标笔记本和文档。编辑后重新打开该文档，可以看到保存的内容。

想在会话中找资料时，可以请助手按标题或路径片段搜索，再给出文档 ID 或路径，要求读取 Markdown 正文。结果标明截断时，请指定要看的片段。**内容空间** 适合定位思源中已打开的笔记本。查找或编辑某篇文档时，回思源页面或用会话工具。

## 从会话保存到思源

要存到指定文档，在会话里明确笔记本、路径、标题和内容。下面是一条示例指令，可按你的目录调整：在「课题 A」笔记本的 `/样本质控` 路径下，以「本周 QA」为标题保存本轮质控结论。写入并收到确认后，从左侧 **思源笔记** 打开该位置，文档正文应包含本轮质控结论。

## 查看自动归档

带最终回复且成功结束的顶层 Agent 轮次，会自动归档到已连接的思源服务。开始任务前，先明确哪些内容可以发往该服务。任务结束后，打开 **思源笔记 → SciForge 工作总结** 笔记本，在 `/SciForge` 路径下按时间找到本轮文档。文档包含请求、最终回复、完成时间和轮次标识，首次归档时会自动创建 `SciForge 工作总结` 笔记本。需要保存任务中的中间结果时，请在会话中指定目标文档。

如果服务断开或暂时无法确认写入结果，待归档内容会留在本机。下次启动 SciForge 或下一轮顶层任务结束时，应用会自动重试。重试时会先找同一轮的文档，避免重复归档。连接恢复后，在原服务的 **SciForge 工作总结** 笔记本打开 `/SciForge`，即可查看补写的文档。
