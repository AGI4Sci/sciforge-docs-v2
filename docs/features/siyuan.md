# 思源笔记

在 SciForge 打开自己的思源服务，查实验笔记、补写记录，或把会话结果存到指定文档。

## 打开方式

1. 准备一个可访问的 HTTP/HTTPS 思源服务。可以用自己部署或订阅的服务器模式服务。需要认证时，提前准备 API Token。
2. 从左侧栏点 **思源笔记**，在页面 **设置** 填服务地址并保存。留空时使用安装配置的默认地址。服务需要认证时，在 **设置** 填 API Token，或在启动环境设置 `SIYUAN_API_TOKEN`。页面设置的 Token 优先，并存入应用加密存储。
3. 页面加载出思源编辑器后，打开目标笔记本和文档，确认可读，编辑前确认有写入权限。报错时可重试，或回 **设置** 检查地址和凭据。

编辑器默认在会话右侧。可以从页头移到左侧、底部或主区域，再调整大小。位置和大小保存在本机。

## 打开已有笔记

从左侧栏打开 **思源笔记**，在编辑器里选目标笔记本和文档。编辑后重新打开该文档，可以看到保存的内容。

想在会话中找资料时，可以请助手按路径片段搜索，再给出文档 ID 或路径，要求读取 Markdown 正文。结果标明截断时，请指定要看的片段。**内容空间** 适合定位思源中已打开的笔记本。查找或编辑某篇文档时，回思源页面或用会话工具。

## 从会话保存到思源

要存到指定文档，在会话里明确笔记本、路径、标题和内容。例如可指定『课题 A』笔记本、/样本质控 路径和『本周 QA』标题，请会话保存本轮质控结论。写入后，从左侧 **思源笔记** 打开该位置，文档正文应包含本轮质控结论。

## 查看自动归档

带最终回复且成功结束的顶层 Agent 轮次，会自动归档到已连接的思源服务。开始任务前，先明确哪些内容可以发往该服务。任务结束后，打开 **思源笔记 → SciForge 工作总结**，在 `/SciForge` 下按时间找本轮文档。文档包含请求、最终回复、时间和轮次标识，首次归档时会创建缺失的笔记本。需要保存任务中的中间结果时，请指定要写的文档。

如果服务不可达或写入结果暂时无法确认，待发内容留在本机，下次启动 SciForge 或运行任务时重试。重试前会查找同一轮次的文档，避免重复创建。连接恢复后，在同一服务的 `/SciForge` 目录查看本轮文档是否出现。
