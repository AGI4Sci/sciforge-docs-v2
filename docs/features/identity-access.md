# 身份与登录

展开工作台左侧边栏，在底部查看**本地账户、云端状态与用量摘要**。点击账户行打开账户面板；点击云端行会打开同一面板并定位到 **SciForge 云端**。设置位于其下方。

## 本地账户是归属标记

本地功能不要求登录。你可以创建本地账户、确认显示名称、选择账户或重命名，也可以退出账户。本地账户不提供安全认证，**不会隔离工作区、聊天、设置、API Key 或工具数据**；在共用电脑上，切换显示名称不能代替操作系统账户隔离。

账户行的删除按钮会先显示确认区域，确认后删除该本地账户及其本机归属数据，操作不可撤销。删除当前账户时，系统选择最早创建的剩余账户；删除最后一个账户后进入未选择账户状态。

这里的**删除账户**属于本地身份管理，不是云端账号注销、项目删除或工作区文件清理。退出本地账户、退出云端登录、断开设备也各有不同作用，操作前核对按钮名称和对象。

## 登录云端并连接设备

1. 先创建或选择本地账户；尚未选择时，“浏览器登录”不可用。
2. 在 **SciForge 云端** 点击 **浏览器登录**，在系统浏览器中完成认证。不需要将密码或 Token 粘贴到会话里。
3. 返回后检查云端身份；尚未连接设备时点击 **连接这台设备**。
4. 只有身份有效且设备活跃，依赖云端身份的协作能力才可继续。

本地账户、模型供应商登录与 SciForge 云端登录属于不同配置。云端功能以当前应用配置和服务可用性为准，不要求用户先搭建某个旧领域包集合。

| 面板状态或动作 | 含义与处理 |
| --- | --- |
| 尚未登录云端 | 本地功能仍可使用，云端项目需要登录 |
| 这台设备尚未连接 | 已登录不能代替设备连接，按界面连接设备 |
| 正在连接这台设备 | 等待设备注册结果，避免连续重复操作 |
| 这台设备已连接 | 设备处于活跃状态，仍需有效的云端身份与项目权限 |
| 这台设备已断开 / 连接异常 | 云端权限不能按正常连接状态使用，检查错误并按提示恢复 |
| 重新登录 | 重新完成云端认证，不代表自动采纳项目邀请或任务 |
| 退出登录 | 清除当前云端登录会话；不应视为已经撤销设备注册 |
| 断开这台设备 | 撤销这台设备的云端访问能力；本地功能仍保留 |

设备被撤销、身份变化或设备有效性无法确认时，云端认证权限会被收回；不要用缓存中的显示名称判断当前仍有授权。登录或连接失败时按面板提示重试，保留原始任务和草稿。

## 用量摘要如何理解

侧边栏底部显示本机记录的**今日**及**近 7 天** Token 与费用摘要；实际扣费请查看模型服务商账单。

加载中、暂无数据、加载失败会分别显示对应提示；没有数据不能解释为没有发生模型请求。

## 凭据与恢复边界

云端登录材料与设备密钥通过平台安全存储管理。安全存储不可用时，不应改用明文文件或把凭据放进聊天、需求和交付文件。

本地身份数据库不可用时，其他本地功能仍可使用。恢复入口会要求输入确认文本，先生成并验证备份，再重置本地身份数据；它不是整个应用的数据重置工具。
