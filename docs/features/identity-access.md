# 身份与登录

身份与登录解决“现在是谁在操作、这台设备是否被授权”。它不参与具体的科研分析，却决定了协作、内容空间等外部能力能否代表当前用户执行。

## 打开方式

- 入口：工作台顶部的**账户**入口，打开 Identity 面板，其中分为“本地账户”和“SciForge 云端”。
- 作用对象：当前安装、当前本地账户、当前 Desktop 设备与云端登录会话。
- 前提：本地功能不要求登录；云端登录需要管理员提供的 SciForge Cloud 地址、账号和可用的系统浏览器。

## 能做什么

| 你要完成的事 | 怎么做 | 产出 |
| --- | --- | --- |
| 标记本机使用者 | 创建或选择本地账户，按需重命名 | 本机归属标记，重启后自动恢复 |
| 登录云端 | 在“SciForge 云端”点击**浏览器登录**，在系统浏览器完成 OIDC 登录 | 当前云端用户与登录会话 |
| 授权这台设备 | 登录后点击**连接这台设备**，完成 Desktop 设备注册 | 可访问云端能力的活跃设备 |
| 结束或转移授权 | 使用**退出登录**或**断开这台设备** | 本地功能保留，云端与跨用户权限立即收回 |

## 典型流程

1. 打开顶部账户，创建或选择一个本地账户；它只用于本机归属，不必与云端名称一致。
2. 点击浏览器登录，在系统浏览器完成账号认证；不要把密码或 Token 粘贴回 SciForge。
3. 返回后点击连接这台设备，确认面板同时显示已登录和“这台设备已连接”。
4. 退出、换机或设备丢失时，先退出登录；确定不再使用这台设备时再断开设备。

## 输入、输出与权限

- 读取：本地账户列表、当前云端用户、设备连接状态与会话有效状态。
- 写入：本地账户选择与显示名称、OIDC 登录会话、设备注册与撤销；不会写入项目内容。
- 审批或外部影响：浏览器登录与设备注册会改变云端账号状态；退出登录、断开设备会立即影响依赖云端身份的功能，需要用户确认。
- 凭据：OIDC 刷新材料、设备签名私钥与 Agent 授权只保存在平台私有存储（macOS Keychain、Windows DPAPI、Linux libsecret/KWallet）；安全存储不可用时失败关闭。
- 不会做什么：不把本地账户当作安全认证，不隔离本机数据，不代填密码，也不把 Token 暴露给界面或其他领域包。

## 已知限制

- 本地账户只是归属标记；同一安装上的工作区、设置和 API Key 不会因切换本地账户而隔离。
- 登录完成不等于设备已注册；跨用户权限需要云端认证身份（`cloud-authenticated` Principal）与 ACTIVE 设备同时成立，设备注册更像一份需要保持有效的租约，而不是一次永久授权。
- 设备被撤销、刷新未确认或 OIDC 用户变化时，云端认证身份立即回退为本地选择，依赖它的协作等能力会停止。
- 退出登录通常保留设备注册；要收回这台设备访问云端的能力，应选择**断开这台设备**。
- 平台安全存储缺失或不安全时会拒绝保存凭据；没有环境变量、明文文件或其他回退路径。
- 外部账号的邮箱、显示名或成员关系不会被当作 SciForge 身份；绑定外部账号必须显式建立并可撤销。
