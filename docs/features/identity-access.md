# 身份与登录

展开工作台左侧边栏，在底部查看**本地账户、云端状态与用量摘要**。点击账户行打开账户面板；点击云端行会打开同一面板并定位到 **SciForge 云端**。设置位于其下方。

## 本地账户是归属标记

- **只使用本地功能**：从左侧边栏底部的账户面板点 **创建账户** 或选择已有本地账户，填写 **显示名称**。修改名称点 **修改名字**，切换或退出点 **退出账户**。
- **连接云端协作**：先选中一个本地账户，再按下一节在 **SciForge 云端** 登录并连接当前设备。已关联云端的账户会把显示名同步给协作者。
- **多人共用一台电脑**：请使用各自的操作系统账户登录电脑。操作系统账户负责隔离工作区、聊天、设置、API Key 和工具数据；SciForge 的本地账户只用于标记本机归属。

账户行的 **删除账户** 按钮会先展开确认区域，确认后删除该本地账户及其本机归属数据，操作不可撤销。删除当前账户时，系统会自动切换到最早创建的剩余账户；删除最后一个账户后，侧边栏底部显示 **尚未选择本地账户**。

这里的 **删除账户** 只作用于本地账户及其归属数据。**退出账户**（本地）、**退出登录**（云端）和 **断开这台设备** 作用对象不同，操作前请看清按钮所在的分区。

## 登录云端并连接设备

1. 先创建或选择本地账户；显示 **尚未选择本地账户** 时，**浏览器登录** 按钮不可用。
2. 在 **SciForge 云端** 点击 **浏览器登录**，在打开的系统浏览器中完成认证。不要将密码或 Token 粘贴到聊天会话里。
3. 返回应用后，面板会显示当前云端账号；设备状态显示 **这台设备尚未连接** 时，点击 **连接这台设备**。
4. 状态变为 **这台设备已连接** 后，即可在侧边栏打开协作项目、**我的工作** 和 **收件箱**。

本地账户、模型供应商登录与 SciForge 云端登录属于不同配置。云端功能以当前应用配置和服务可用性为准。

| 面板状态或动作 | 含义与处理 |
| --- | --- |
| 尚未登录云端 | 本地功能仍可使用，云端项目需要登录 |
| 这台设备尚未连接 | 已登录不能代替设备连接，按界面连接设备 |
| 正在连接这台设备 | 等待设备注册结果，避免连续重复操作 |
| 这台设备已连接 | 设备处于活跃状态，仍需有效的云端身份与项目权限 |
| 这台设备已断开 / 连接异常 | 云端权限不能按正常连接状态使用，检查错误并按提示恢复 |
| 重新登录 | 重新完成云端认证，不代表自动采纳项目邀请或任务 |
| 退出登录 | 清除当前云端登录会话；不应视为已经撤销设备注册 |
| 断开这台设备 | 撤销这台设备的云端访问能力；本地功能仍保留 |

设备被撤销、身份变化或设备有效性无法确认时，云端认证权限会被收回；不要用缓存中的显示名称判断当前仍有授权。登录或连接失败时按面板提示重试，保留原始任务和草稿。

## 用量摘要如何理解

侧边栏底部显示本机记录的**今日**及**近 7 天** Token 与费用摘要；实际扣费请查看模型服务商账单。

加载中、暂无数据、加载失败会分别显示对应提示；没有数据不能解释为没有发生模型请求。

## 凭据与恢复边界

云端登录材料与设备密钥通过平台安全存储管理。安全存储不可用时，不应改用明文文件或把凭据放进聊天、需求和交付文件。

本地身份数据库不可用时，其他本地功能仍可使用。恢复入口会要求输入确认文本，先生成并验证备份，再重置本地身份数据；它不是整个应用的数据重置工具。
