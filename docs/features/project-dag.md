# Project DAG

Project DAG 汇总同一项目内多个会话的证据，帮助你了解项目目前有哪些结论、哪些问题仍待审查。先在各会话的 [Evidence DAG](./evidence-dag.md) 更新并保存证据图，再回到项目图点击 **立即更新**。会话中保存了新证据后，项目图仍需手动更新。

## 打开方式

- 入口：右侧面板 **项目 DAG**；也可以从项目、目标或历史快照打开对应视图。
- 作用对象：当前工作区对应的项目及各会话已保存的证据图。
- 前提：项目内至少有一个已保存的会话证据图，且证据图和项目图功能可用。

## 更新和审查项目图

1. 在各个会话中完成分析、保存来源和结果，并分别更新 Evidence DAG。等待各会话证据图保存完成。
2. 打开项目 DAG，在 **项目目标** 填写标题与描述，点击 **保存目标**。
3. 点击 **立即更新**，等待排队、执行和保存全部完成，再检查本次项目图。只保存会话证据或关闭面板，都不会自动生成新的项目图。
4. 查看需要关注的事项、审计状态和供审查使用的材料。选择重要结论，逐项检查：结论说了什么？依据哪些来源？能否追查到原始记录？能否按原条件重新运行分析？还缺哪些证据？
5. 需要核对细节时，打开对应会话的 Evidence DAG。补齐来源或结果后，先保存会话证据图，再手动更新项目图。

## 审查时注意

- 确认正在审查的是本次更新后的图。新图保存后，旧图的审计结果会标记为过期，应结合当前图重新核对。
- 审计用于检查已经保存的项目图。审计失败不会撤销已保存的图，也不会直接修改结论。
- 无权查看的来源会隐藏具体内容，只显示有限的状态和缺口提示。审查时应注明无法核对的部分。
- 项目图使用各会话已保存的证据图；尚未保存的分析结果需要先回到会话中整理。

## 保存与分享

保存目标和更新项目图会新增项目记录，方便之后回顾。面板中的操作针对本地项目记录；发布或向外发送内容仍需按应用要求授权。分享前应检查来源权限，并交代未验证的结论和证据缺口。
