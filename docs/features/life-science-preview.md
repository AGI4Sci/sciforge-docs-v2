# 生命科学预览（Life Science Preview）

生命科学预览随 SciForge 提供，无需另装插件。它用于查看科学文件的结构和摘要，帮助你找到需要继续分析的内容；完整数据分析仍需读取原文件并运行相应工具。

## 打开文件

在当前工作区的文件面板中打开文件。支持的格式会显示对应的科学预览，其他格式按普通文件打开。

本地和远程工作区都可以使用。远程文件从远端读取，查看预览时无需先把整份文件下载到本机；读取范围仍受工作区权限和大小限制。

## 支持的格式与预览内容

| 用途 | 支持格式 | 预览内容 |
| --- | --- | --- |
| 查看分子结构 | `.pdb`、`.cif`、`.mmcif`、`.sdf`、`.mol`、`.mol2`、`.xyz` | 链、残基和配体摘要，以及 Mol* 三维视图；坐标可用时可测量距离、角度或二面角 |
| 查看序列与基因组 | `.fasta`、`.fa`、`.fna`、`.faa`、`.fastq`、`.gb`、`.gbk`、`.gff`、`.gff3`、`.gtf`、`.bed`、`.vcf` | 记录数、长度、特征、区间和变异摘要；可选择分析区域 |
| 查看组学文件信息 | `.h5ad`、`.loom`、`.mtx`、`.h5`、`.hdf5`、`.zarr` | 可读取的矩阵维度、观测与变量字段名、降维结果名称等文件信息；不读取完整矩阵 |
| 查看生物影像信息 | `.tif`、`.tiff`、`.ome.tif`、`.ome.tiff`、`.czi`、`.svs`、`.ndpi` | 尺寸、通道和 OME 元数据；支持时可选择区域（ROI）与通道，或查看 TIFF/OME-TIFF 的缩略图和局部图像 |
| 查看光谱与流式细胞数据摘要 | `.mzml`、`.mzxml`、`.mgf`、`.fcs` | 可读取的扫描或事件摘要、峰计数、强度范围和部分峰数据；可添加峰区间注释 |
| 查看配套索引文件 | `.fai`、`.gzi`、`.tbi`、`.csi` | 识别序列或基因组文件的配套索引，供后续操作引用；不将索引解析为序列或变异数据 |

## 选择分子区域

在分子预览的选择面板中选择链或配体，三维视图会高亮对应部分；点击清空可取消高亮。选区可以包含多个链、残基、原子或配体。

**选择状态与源文件分开。** 选择面板中的操作更新当前文件的预览会话状态，不会把选区写入 PDB、CIF 等源文件。预览会话与聊天会话不是同一份记录，也不能将画面中的高亮视为永久保存。

关闭再打开文件后，请核对需要继续使用的选区；重要的链、残基或原子编号也应写进分析要求。这样即使选择状态未保留，AI 助手仍能按明确范围继续分析。

## 从预览继续分析

1. 确认当前工作区，在文件面板打开目标文件。
2. 核对文件名、格式、大小和摘要，确认打开的是目标文件。
3. 根据任务选择区域、残基或通道，并在会话中向 AI 助手说明文件路径、分析范围和目标。
4. 使用远程工作区时，让助手直接读取远端原文件；仅为查看预览，无需复制整份大文件。
5. 检查分析所用的原始数据、命令和运行结果。预览摘要只用于定位和理解文件，不能代替计算记录。

## 读取范围与导出副本

- 摘要只读取文件开头的一部分：文本最多 **2 MB（2,000,000 字节）**，二进制最多 **4 MiB（4,194,304 字节）**。超出部分会提示未完整显示，摘要中的数量不一定代表整份文件。
- 预览不修改源文件。导出会将源文件按原格式复制到新的工作区路径，不转换格式或修复损坏文件。
- 打开与读取无需确认；导出副本需要确认，执行前核对保存路径。
- 预览和导出不会上传工作区文件。需要上传、转换或修复时，应单独向助手说明任务。

## 各类预览的限制

- 预览中的条目列表可能只显示前一部分，并标出未完整显示的情况；选择范围过大时会提示无法接受，请缩小范围。
- 组学文件主要显示文件信息，不读取 HDF5、AnnData、Loom 或 Zarr 中的完整矩阵，不能直接用于定量分析。
- CZI、SVS、NDPI 只显示可读取的文件信息，不显示实际像素内容。
- FCS 主要显示可读取的文件头、关键词和部分峰数据，不提供完整事件矩阵。
- TIFF/OME-TIFF 会尝试生成缩略图和局部图像；压缩格式或非 8 位图像可能只显示文件信息。
- 序列与基因组摘要基于部分文本，不能替代完整格式校验或变异检测。
- 轨迹与密度文件可以交给 Mol* 三维视图查看，但不会生成链、残基和配体摘要。
