# 生命科学预览（Life Science Preview）

从工作区打开科学文件，先看摘要，再选出要分析的链、区间或通道。生命科学预览随 SciForge 的 Biology Workbench 提供，本页对应 **1.1.3**。

## 打开文件

从最右侧工具栏打开 **文件**，选中当前工作区的目标文件。受支持的格式会直接打开对应的科学预览，显示文件名、格式和结构化摘要；其余格式按普通文件打开。远程工作区可直接从远端读取预览，读取范围受工作区权限和大小限制。

## 支持的格式与预览内容

| 文件格式 | 打开后看到什么 | 接下来可以做什么 |
| --- | --- | --- |
| `.pdb`、`.cif`、`.mmcif`、`.sdf`、`.mol`、`.mol2`、`.xyz` | 链、残基和配体摘要，Mol* 三维视图 | 选中分子区域；有坐标时测量距离、角度或二面角。 |
| `.fasta`、`.fa`、`.fna`、`.faa`、`.fastq`、`.gb`、`.gbk`、`.gff`、`.gff3`、`.gtf`、`.bed`、`.vcf` | 已读取部分的记录数、长度、特征、区间或变异摘要 | 选区间，随后在原文件中按坐标读取、校验或分析。 |
| `.h5ad`、`.loom`、`.mtx`、`.h5`、`.hdf5`、`.zarr` | 已读取部分的矩阵维度、观测与变量字段名、降维结果名称 | 记下所需字段名，再用相应工具从原文件读取完整矩阵。 |
| `.tif`、`.tiff`、`.ome.tif`、`.ome.tiff`、`.czi`、`.svs`、`.ndpi` | 尺寸、通道和 OME 元数据。支持的 TIFF/OME-TIFF 可显示缩略图和局部图像 | 可选时指定区域（ROI）及通道。CZI、SVS、NDPI 的像素请用对应影像工具读；压缩或非 8 位 TIFF 若仅显示文件信息，也可改用影像工具。 |
| `.mzml`、`.mzxml`、`.mgf`、`.fcs` | 已读取部分的扫描或事件摘要、峰计数、强度范围和抽样峰数据。FCS 主要读取文件头和关键词摘要 | 在可用的谱图里加峰区间注释。要读完整事件矩阵，用相应工具打开 FCS 原文件。 |
| `.fai`、`.gzi`、`.tbi`、`.csi` | 序列或基因组文件的配套索引 | 后续处理时把索引与对应数据文件一起引用。 |

谱图、组学矩阵和生物影像按卡片显示摘要。想看后面的卡片，在预览内向下滚动。要看轨迹或密度，使用 Mol* 视图；要查链和残基，打开对应的结构文件。

## 选择分子区域

在 Mol* 三维视图单击残基，把它加入当前选区。再次单击已选残基可取消该项，点空白处可清空。要改选整条链，在下方 **Selection** 面板点 `Chain <ID>` 按钮，它会用整条链替换当前选区；也可从同一面板点配体按钮或清除按钮。点完后，三维视图会高亮所选区域，**Selection** 面板会列出当前选中的链、残基、原子或配体。

逐个选残基时用普通单击。Mol* 的 **Shift** 点击会选中聚合物上的一段连续区间；若 **Selection** 列表中的范围与预期不符，点空白处或清除按钮清空，再逐个单击需要的残基。

选区保存在文件的预览会话状态。关掉文件后重新打开时，先看三维高亮和 **Selection** 列表是否仍为所需范围。需要在聊天里继续分析时，把链名和残基或原子编号写进任务要求。

## 从预览继续分析

在会话中写出文件路径、选区或通道编号，以及要分析的问题。远程工作区请指定远端原文件路径。摘要适合定位区间或字段，定量分析、完整格式校验或变异检测应让脚本或工具读取原文件，并在回复中返回所用文件、命令与结果。

## 读取范围与导出副本

预览摘要读取文件开头的一部分。文本最多 **2 MB（2,000,000 字节）**，二进制最多 **4 MiB（4,194,304 字节）**。出现未完整显示提示时，摘要里的计数只覆盖已读取的部分。需要整份文件的统计量时，读取原文件重新计算。选区过大时，可缩小后再试。

要导出副本，从右侧 **文件** 面板打开要复制的科学文件，保留预览，在支持文件预览工具的会话中指定从该文件的预览导出原格式副本。给出源文件路径和新的工作区相对路径。例如，打开一个 FASTA 文件后，可以在会话中指定将它的原格式副本保存到 `exports/copy.fasta`。这是示例路径，可换成自己的文件名。

打开预览和读取摘要无需确认。导出会显示写入确认，先看源文件和目标路径，再批准。完成后，在 **文件** 面板打开目标目录，副本应出现在指定路径，扩展名与源文件相同。
