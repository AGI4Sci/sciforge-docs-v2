# 生命科学预览（Life Science Preview）

生命科学预览随 SciForge 提供，可以直接打开序列、分子结构等科学文件，无需另装插件。

## 打开方式

- 入口：文件面板中的文件预览；打开受支持的本地或远程工作区文件。
- 作用对象：工作区文件；由扩展名和预览清单选择对应视图。
- 前提：文件位于当前工作区；远程工作区由远端 Workspace Host 读取，界面不要求先把整份文件下载到本机。

## 能做什么

| 你要完成的事 | 怎么做 | 产出 |
| --- | --- | --- |
| 查看分子结构 | 打开 `.pdb`、`.cif`、`.mmcif`、`.sdf`、`.mol`、`.mol2`、`.xyz` | 链、残基、配体摘要；Mol* 视图；坐标可用时测量距离、角度或二面角 |
| 查看序列与基因组 | 打开 `.fasta`、`.fa`、`.fna`、`.faa`、`.fastq`、`.gb`、`.gbk`、`.gff`、`.gff3`、`.gtf`、`.bed`、`.vcf` | 记录数、长度、特征、区间、变异摘要与区域选择 |
| 查看组学矩阵 | 打开 `.h5ad`、`.loom`、`.mtx`、`.h5`、`.hdf5`、`.zarr` | 矩阵维度、观测/变量键、嵌入名称与元数据摘要 |
| 查看生物影像 | 打开 `.tif`、`.tiff`、`.ome.tif`、`.ome.tiff`、`.czi`、`.svs`、`.ndpi` | 尺寸、通道、OME 元数据、区域（ROI）与通道选择；TIFF/OME-TIFF 的缩略图与瓦片 |
| 查看光谱与蛋白质组 | 打开 `.mzml`、`.mzxml`、`.mgf`、`.fcs` | 扫描/事件摘要、峰计数、强度范围、采样峰与峰区间注释 |
| 携带伴随索引 | 打开 `.fai`、`.gzi`、`.tbi`、`.csi` | 作为序列或基因组文件的伴随索引传输，供后续对象引用 |

**不解析什么：** 组学只读元数据，不解码 HDF5、AnnData、Loom 或 Zarr 矩阵；CZI、SVS、NDPI 只提供容器元数据占位，不做像素解码；FCS 以可见头、关键词和采样峰摘要为主，不提供完整事件矩阵；轨迹与密度文件可以交给 Mol* 视图，但它们不在链、残基与配体摘要的解析范围内。预览是读取辅助，不是校验级格式解析或分析工具。

## 分子选区与保存边界

分子选区可表达多个链、残基、原子和配体。Inspector 提供链、配体和清空操作；宿主回传的选区会同步到 Mol*，包括异步初始化期间的最新选区。源文件保持只读。

修改选区后，请重新打开文件，确认选择已保存。快速连续选择时尤其需要检查。

## 典型流程

1. 确认顶部工作区位置，在文件面板打开目标文件。
2. 核对预览中的格式、大小、维度或记录数，确认没有打开错文件。
3. 需要继续分析时，建立区域、残基或通道选择，让 Agent 在原文件上工作。
4. 远程工作区中先确认读取发生在远端；不要让 Agent 为预览复制整份大文件。
5. 预览结果只作为会话上下文，关键结论仍应回到原文件与计算记录。

## 输入、输出与权限

- 读取：预览摘要读取文件开头部分，文本最多 2,000,000 字节，二进制最多 4 MiB；超出部分带截断标记，由拥有数据的 Workspace Host 执行。
- 写入：预览本身不修改源文件；导出只把同格式源文件复制到新的工作区路径。
- 审批或外部影响：打开与读取不需要审批；导出副本需要确认，并写入新的工作区路径。
- 不会做什么：不转换格式、不修复损坏文件、不把预览摘要当作完整数据，也不上传工作区文件。

## 已知限制

- 观察列表会截断并带显式标记，过大的选区会被拒绝。
- 组学矩阵、专有影像容器和 FCS 为元数据或占位预览，不能据此做定量分析。
- 生物影像的缩略图与瓦片只在 TIFF/OME-TIFF 上尝试；压缩或非 8 位 TIFF 可能退化为元数据。
- 序列与基因组预览基于截断文本，不能替代完整格式校验或变异检测。
- 未注册的扩展名不会进入上述专用视图，仍按普通工作区文件处理。
