# 科研图件（Scientific Figures）

先用两行示例数据画一张折线图。图出来后，你可以改样式、比较候选图，再从历史找回当时的代码和数据。

## 安装并打开科研图件

1. 打开 [扩展 → 市场](./extensions.md)，找到 **Scientific Figures**。显示 **安装** 时可从市场安装，条目显示 **已启用** 后就能打开插件。若列在 **暂不可安装**，展开条目查看原因。已启用兼容版本的读者可从下一步开始。
2. 在通过安全检查的 macOS 上打开一个**可写的本地工作区**。进入已配置模型的 **DSH 会话**。绘图用 Python，所用解释器需安装 Matplotlib。需要指定解释器时，在插件配置中设置 `pythonCommand`。
3. 在右侧栏的插件选择器选 **科研图件**。看到 **图件** 页后，即可开始选数据。

<details>
<summary>核对插件版本、平台和入口</summary>

本页的插件操作对应 **0.4.0-mvp.13**。

原生 DSH 的版本范围是 `>=0.2.1-rc.4 <0.3.0`，Node 要求 >=22。安装包内含对应平台的原生 Canvas 组件，请按平台、架构及 Linux libc 选择构建。SciForge 中的绘图执行支持 macOS，Windows 和 Linux 可安装兼容包，但该入口的执行仍限于 macOS。已有 R 或 MATLAB 脚本时，先用 Python 实现所需绘图步骤。

在原生 DSH 中，打开会话输入区的 **Figures** 面板，或输入 `/scientific-figures`。

</details>

## 选择数据和代码，生成第一张图

1. 在当前工作区把以下内容保存为 `data/trend.csv`。

   ```csv
   time,response
   0,1.2
   1,1.8
   ```

2. 在 **科研图件 → 新建** 选 **从数据开始**，在 **数据文件** 填 `data/trend.csv`。在要求框写下要画什么。下面是一段示例：

   ```text
   读取 data/trend.csv，以 time 为横轴、response 为纵轴，画一张蓝色折线图。
   表中没有提供单位，坐标轴用列名标注。保存数据和代码，实际运行并发布 PNG。
   ```

3. 点 **开始绘图**。在左侧会话查看运行结果，再回到 **图件** 页点 **刷新**，选中本次图件。看到横轴从 0 到 1、纵轴从 1.2 到 1.8 的折线，即可继续修改。

已有脚本时，在 **新建** 选 **已有数据和代码**，填写数据与 Python 代码的工作区相对路径，再写绘图要求。你也可以附一张原图作参照，界面将它标为“用户提供、尚未验证”。用新运行产出的 PNG 检查代码和输入是否画出了预期结果。

![新建页的示例数据、绘图要求和开始绘图按钮](/img/docs/scientific-figures/guide-new-from-data.png)

## 找到图片、代码和运行结果

在 **图件** 页选中刚画好的图。从 **所有版本与来源** 查看对应的代码版本和运行记录，再到 **代码与运行** 选择对应运行并点 **读取运行**，核对参数、输入、环境和日志。两类记录每页各显示 20 条摘要，点 **更多代码版本** 或 **更多运行记录** 翻页。

每个代码版本保存当时的数据副本、参数及来源版本。复跑某一版时，选中那一版，使用它保存的代码、参数和输入。要改用工作区中更新过的原文件，在高级设置勾选 **重新读取工作区数据**，再保存新版本。

## 修改图件，比较后再接受

1. 在 **图件** 页选中示例折线图，描述想改的地方。例如可以要求沿用原数据，把折线改为橙色。助手保存新代码并运行后，点 **刷新**，橙色折线会出现在候选中。
2. 在 **当前图 / 修改后** 对照两张图。有多张候选时，用 **候选** 下拉框切换。
3. 满意时点 **申请接受**，再到会话中核对这张候选并点 **允许**。橙色折线显示为 **当前图** 后，旧图和旧代码仍可在历史中查看。要维持现有图片，点 **保留当前图**。

如果候选生成后当前图又变了，先选中现在的图，再生成新的候选。

![当前蓝色折线和橙色候选折线的对比](/img/docs/scientific-figures/guide-candidate-comparison.png)

## 分析文件、历史与恢复

**把分析结果用到下一步。** 在脚本中把 `cleaned.csv`、`summary.json` 或 `rules.txt` 等写入 `SCIENTIFIC_FIGURES_OUTPUT_DIR`。打开 **代码与运行**，选中产生这些文件的那次运行并点 **读取运行**，从 **输出文件** 核对路径和摘要。要继续分析，可在会话中提交分析任务，同时注明运行记录和输出文件；也可以按下方步骤手工引用。保存新版本后，**版本与输入快照** 会列出输入副本。脚本中的中间变量需要先写成文件。

<details>
<summary>手工引用和输出上限</summary>

手工编辑代码时，打开 **代码与运行 → 高级设置：参数、输入与文件**。已有父版本时，先勾选 **重新读取工作区数据**。把 `.scientific-figures/` 与 **输出文件** 显示的路径（工具返回的 `output.path`）拼起来，写入 **工作区输入路径 JSON**，例如 `[".scientific-figures/运行记录中的路径/cleaned.csv"]`。该输入框对应保存代码版本的 `inputPaths`。点 **保存并冻结代码**，展开 **版本与输入快照** 核对新副本。

| 输出 | 格式 | 每次运行的上限 |
| --- | --- | --- |
| 可发布为图件或候选 | PNG | 最多 16 个，单个 20 MiB，合计 64 MiB |
| 供后续分析 | 有效 UTF-8 的 CSV、TSV、TXT，或可解析的 JSON | 最多 32 个，单个 8 MiB，合计 32 MiB |

保存失败时，在对应运行中查看提示，按格式和数量要求修正后再运行。

</details>

**补齐中断的保存。** 打开 **代码与运行 → 尚未结束或中断的运行**。找到对应运行后点 **完成中断记录**。补存完成后，这条记录出现在运行历史中，打开可看到原日志和输出。若提示结果缺失、进程状态未确认或记录仍被占用，先处理提示中的原因。运行失败时，在运行详情读错误日志，修正代码或环境后从 **执行已冻结 Python** 重跑。单条记录损坏时，可继续查看其他记录和分页。

## 查看代码并手动运行

1. 在 **代码与运行** 选中版本，点 **载入版本**。改完后点 **保存并冻结代码**，查看新版本是否出现在列表中。
2. 点 **执行已冻结 Python**，在运行详情核对状态、输入、参数和输出。排查问题时可展开代码比较、环境与日志。
3. 运行成功后，在 **输出文件** 选 PNG，点 **发布为新图件文档**。要添加到已有图件，勾选 **发布为现有文档的候选图**，选 **目标文档**，点 **读取并选定当前基线**，出现 **明确基线** 后点 **发布为候选图**。回到 **图件** 页，新图会出现在图件列表中，候选则出现在目标图件的 **候选** 下拉框。

![代码与运行页的示例源码、成功状态和输出文件](/img/docs/scientific-figures/guide-code-and-runs.png)

## 按已保存的说明重建环境

在 **代码与运行** 读取成功运行，从 **输出文件** 的路径找到对应运行目录，打开其中的 `_environment/`：

- `environment.json`：核对原运行所用的 Python、系统和依赖信息，排查新旧环境差异。
- `requirements.txt`：按原运行记录的精确包版本安装 Python 依赖。
- `REBUILD.md`：按说明新建独立环境、安装依赖并准备重跑。

系统库和驱动需要在目标机器上准备。更换系统或 Python 版本后，用保存的代码和输入试跑，核对主要输出及数值。

## 遇到问题时怎么办

| 看到什么 | 接下来做什么 |
| --- | --- |
| 会话已有结果，图件页仍显示旧图 | 点 **刷新**，再检查选中的图件和候选。 |
| 发送失败 | 保留输入，检查 DSH 会话及模型连接，恢复后重试。 |
| 找不到 Python 或 Matplotlib | 在 **代码与运行** 看报错，检查解释器路径及该解释器的 Matplotlib 安装。 |
| 会话附件显示 `File not found` | 先重新读取对应运行，再核对图片文件和插件版本。 |
| 候选未成为当前图 | 回会话检查是否已点 **允许**。如果当前图已变，基于新当前图生成候选。 |
| 代码执行失败 | 打开运行日志，修正后重跑。状态成功后再发布候选。 |

## 当前能力与使用限制

图件记录保存在工作区的 `.scientific-figures/`。要把图件纳入科研记录，按 [证据与可复现性](./evidence-and-reproducibility.md) 保留数据、代码及运行结果。

开始执行前，确认首次会话的工作区可写、隔离可用，且工作区位于系统临时目录之外。写入范围由首次会话的工作区确定，切换目录会沿用原有权限。只执行可信的本地 Python 代码，因为隔离限制写入，脚本仍可能读取其他文件或访问网络。发送绘图数据前，请核对模型服务的数据策略。
