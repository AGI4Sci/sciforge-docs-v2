# Skills、MCP 与扩展

先按任务选入口。要增加一个工具或面板，打开 **扩展**。想复用一套做事方法，找 **Skills**。需要在会话中访问外部工具或数据时，配置 MCP。

## 打开扩展中心

展开左侧边栏，点 **扩展**。打开条目详情，核对发布者、版本、来源、状态、权限，以及此扩展提供的工具和功能。

要打开扩展页面，去左侧导航。要调出工具面板，找最右侧纵向工具栏。要用扩展预览文件，从 **文件** 面板打开对应格式。工具栏放不下时，展开 **更多工具**。需要调整支持的入口时，打开 **自定义工具栏**。支持停靠的页面可放到左侧、右侧、底部或主区域。

![公开源码构建中的扩展中心](/img/docs/guides/extensions-center-public-zh.png)
*从左侧进入扩展，核对条目来源。*

![内置扩展的版本和来源](/img/docs/guides/extensions-details-public-zh.png)
*打开详情，查看版本、来源和运行状态。*

## 查看来源、安装与启用

| 你要做什么 | 入口及结果 |
| --- | --- |
| 查用途和适配状态 | 打开 [SciForge 公开目录](https://agi4sci.github.io/SciForge-market/)，点条目查看适用任务与公开状态。 |
| 在桌面端安装 DSH 插件 | 打开 **扩展 → 市场**。可安装的条目显示 **安装**，市场提供的是 `.sciforge-dsh-plugin` 包。 |
| 使用客户端内置模块 | 在 **扩展** 打开内置条目，查看启用状态和入口位置。 |
| 安装本地签名扩展 | 在 **扩展 → 从文件安装** 选择客户端支持的 `.sciforge-plugin`，核对发布者、签名和版本兼容性。 |

**从桌面市场安装。** 找到可安装条目后，先看详情里的发布者、版本、工具权限及宿主接口要求，再点 **安装 → 批准并安装**。看到 **已启用** 后，打开教程中的入口试一次。已有插件可以在条目详情按可用操作启用、禁用、卸载或回滚。界面要求重启时，重启后再检查入口。

如果 **市场** 将条目列在 **暂不可安装**，展开该栏查看原因。已启用的插件可从其功能入口打开。开发构建的插件请按维护者提供的流程使用。

![桌面市场的暂不可安装分组](/img/docs/guides/extensions-market-public-zh.png)
*展开 **暂不可安装**，可以看到每个条目的原因。*

### 插件使用教程

以下三个都是 DSH 插件。用已安装并启用的兼容版本试做对应的小任务。

- **Anchored Comments**。在可保存批注的工作区打开 **研究记录**，在同一条目里选中「缺失值已填为 0」，点 **添加批注**，写下「请核对空值是否表示未测量」，点 **Save**。如需回查，在会话中查询该条批注，结果应包含所选原文和保存的意见。步骤见 [锚定批注](./anchored-comments.md)。
- **Change Inspector**。在演示工作区用会话修改 `notes.md`，再从同一会话查询已记录的文件改动。此例的改动清单应列出 `notes.md`，差异中能看到新增的一行说明。还有记录时继续查看下一批。步骤见 [变更检查](./change-inspector.md)。
- **Scientific Figures**。在通过安全检查的 macOS 上准备可写本地工作区、已配置模型的 DSH 会话及 Python、Matplotlib。用 **科研图件 → 新建 → 从数据开始** 画示例折线，刷新后检查 PNG。后续样式修改可先比较候选。步骤见 [科研图件](./scientific-plotting.md)。

## 使用 Skill

在 **扩展 → Skills** 找适合任务的方法。启用前看项目级或全局作用范围，核对触发条件、用到的脚本与资料、所需软件和凭据。如果 Skill 会安装依赖、访问网络或写文件，在执行时核对任务权限。可以先用小样本试做，再确认结果符合 Skill 说明中的检查条件。

![Skills 管理界面](/img/docs/guides/skills-center.png)
*在 Skills 中查看项目级和全局条目。*

## 连接 MCP Server

1. 展开左侧边栏，点底部 **设置 → AI 助手**，找到会话所用的 Runtime。需要接入自备 MCP Server 时，使用该 Runtime 提供的 MCP 配置入口。本文对应的 SciForge 桌面构建从 **AI 助手** 管理执行者，扩展市场负责安装插件；桌面设置里没有通用的自定义 MCP 编辑器。若会话所用的 Runtime 未开放自定义连接，请使用它已经提供的工具。
2. 在支持自定义连接的 Runtime 中打开 MCP 服务配置，按服务说明填入启动命令或服务地址。保存前查看来源、版本、启动方式或地址、凭据的权限范围、工具会读取、写入或发出的数据。把凭据填在配置提供的凭据入口。
3. 保存后回到会话，用该服务做一次只读查询。例如列出一个已知的资源，结果中应出现该资源的名称或 ID。涉及发送、上传、删除或写入时，先明确目标、数据去向和授权。完成后到目标系统查看新增或修改的内容。

## 使用 Computer Use

使用 Codex 或 Claude Code 时，从设置启用 Computer Use，查看运行状态。在 macOS 同时检查屏幕录制、辅助功能权限。先指定要操作的浏览器页面或 Electron 内嵌页面及任务范围，遇到登录、授权、付款、发送或删除时核对具体动作，再查看实际页面结果。

![Computer Use 配置](/img/docs/guides/ai-assistants-computer-use.jpg)
*在设置中查看启用状态和系统权限。*

## 找不到功能时

先在 **扩展** 核对启用状态、错误或重启提示，并确认工作区权限和 Runtime 支持所需能力。工具面板未显示时，查 **更多工具** 和 **自定义工具栏**。运行时找不到已启用的 Skill 或 MCP 时，新建会话再检查。若本地扩展安装失败，按报错检查包格式、签名、发布者及兼容版本后再试。
