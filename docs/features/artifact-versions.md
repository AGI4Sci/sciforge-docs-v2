# 产物版本（Artifact Versions）

Artifact Versions 帮你保存同一张图、同一份数据或其他文件的不同版本。每次保存都会留下独立版本，方便查看、比较和恢复；修改工作区文件后，需要再次保存产物版本，才能把这次结果留在历史中。研究过程可通过 [Research Checkpoints](./research-checkpoints.md) 回顾，结论与来源的关系可在 [Evidence DAG](./evidence-dag.md) 中检查。

## 打开方式

- 入口：工作台科研摘要的 **Artifacts** 区域列出最近产物；选择具体条目后，在右侧 **科研** 面板查看版本。
- 作用对象：当前工作区中的单个产物，例如图表、数据、日志或代码文件。
- 前提：会话绑定工作区，且 Agent 或生成产物的插件已保存产物版本。

## 保存和检查版本

1. 在任务中生成图表或数据，确认实际文件位于当前工作区。
2. 让 Agent 保存这次产物的独立版本，并关联生成它所用的输入和相关文件。
3. 在 **Artifacts** 列表中找到产物，打开后核对当前选中的版本、内容摘要与相关文件。
4. 修改产物后再次保存，在科研档案的 **版本** 区选择要比较的两个版本，检查内容和生成信息的差异。
5. 需要使用旧结果时，选择历史版本并恢复为新版本。恢复会保留已有历史，之后请确认新版本及实际文件状态。

## 导出与导入

交付前，在科研档案中明确选择要导出的产物版本，再导出 Bundle。导出会写出文件，界面会先请求确认。请检查包内所有需要的版本及相关文件是否齐全，并确认它们都允许访问和导出；任何必需版本不可见或不允许导出时，整次导出都会失败。

在目标工作区导入前先校验 Bundle。导入会增加版本记录；缺少依赖、历史不一致或内容损坏的包会被拒绝。分享前还应检查包内是否包含不宜外发的数据。

## 使用提示

- 只有已经保存过的产物才会出现在版本列表中。[科研图件](./scientific-plotting.md)自行保存图件历史，不会自动登记到这里；需要关联时应另外保存产物版本。
- 部分版本会引用工作区文件。文件被移动、修改或删除后，查看时可能提示来源变化或缺失；请先核对实际文件。
- 查看、比较、恢复和导入都受版本访问权限限制。历史列表中的条目也可能无法打开或导出。
- 版本记录不能替代对结果的科学审查；交付前仍需检查输入、方法和结论。
