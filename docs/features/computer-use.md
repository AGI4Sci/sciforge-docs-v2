# 电脑操作

Computer Use 让受支持的 Runtime 通过本地 Backend 操作桌面中的图形界面，把观察、点击和输入变成受治理的 MCP 工具。它适合必须经过界面完成、又没有稳定 API 的步骤；每次会改变状态的动作都需要一次已确认的调用。

## 打开方式

- 入口：**设置 → AI 助手 → Computer use**；开启总开关并选择允许使用它的 Runtime。
- 作用对象：当前会话绑定并授权的图形界面目标；当前实现使用浏览器 CDP 后端处理浏览器页面和 Electron 内嵌页面。
- 前提：本地 Computer Use Backend 正常运行；macOS 上还需授予屏幕录制与辅助功能权限。
- 连接方式：由 SciForge 启动托管 MCP Server，把有界的工具提供给 Codex/Claude Code；不需要手工配置 MCP 命令。

## 能做什么

| 你要完成的事 | 怎么做 | 产出 |
| --- | --- | --- |
| 检查可用性 | 在设置页查看 Backend 与系统权限状态 | 可用或不可用状态，不会静默回退 |
| 观察目标 | 让 Agent 先读取当前目标与可交互元素 | 有界的页面或目标观察 |
| 执行一步操作 | 在明确指令下点击、输入、按键或滚动 | 结构化动作结果与页面版本 |
| 中止或释放 | 停止当前任务或释放会话 | 取消在途动作并清理绑定 |

## 典型流程

1. 在设置中启用 Computer Use，只勾选本次任务需要的 Runtime。
2. 检查 Backend 状态，并在 macOS 系统设置中确认屏幕录制与辅助功能已授权。
3. 在会话中说明目标页面、要完成的结果、停止条件和禁止动作。
4. 先让 Agent 观察，再逐步执行动作；每次会改变状态的调用都需要你确认。
5. 完成后释放会话，并回到界面核对结果，不要把工具返回成功当作业务结果已确认。

## 输入、输出与权限

- 读取：当前目标的结构化观察、可交互元素和有界截图；只读查询不需要确认。
- 写入：点击、输入、按键、滚动等界面动作；每次变更都必须绑定一次可信的、已确认的调用。
- 审批或外部影响：登录、授权、发送、上传、购买或付款、删除和提交正式结果等动作，必须在执行当下由用户确认；确认只针对这一条调用，不会自动授权后续同类动作。
- 数据边界：画面和观察结果可能包含账号、患者信息或未公开数据，应按敏感数据处理；不要把密码、验证码或支付信息交给 Agent 代填。
- 不会做什么：不绕过系统权限，不在回合结束后继续操作，不承诺任意桌面应用都可自动化，也不会在 Backend 不可用时改用其他后端。

## 已知限制

- 当前执行后端是浏览器 CDP，目标限于浏览器页面与 Electron 内嵌页面（例如 Browser Preview）；它不是任意桌面应用的通用自动化工具。
- 需要本地 Backend 和对应 Runtime 接入；Backend 不可用时会显式报错，不会静默降级。
- 只支持 Codex 与 Claude Code；其他 Runtime 不会收到这组工具。
- 截图与观察结果默认按不可信、可能敏感的数据处理，导出前应脱敏。
- 会话结束后会回收该回合的绑定，不能把 Computer Use 当作无人值守的长期自动化。
