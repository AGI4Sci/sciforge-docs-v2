# 获取与整理数据

使用数据提供方支持的客户端，或在自己配置的环境中运行下载脚本。先确认访问权限、使用条款与所需存储空间；认证信息按[权限与安全](../operations/security.md)管理。

1. 确认数据来源 URL、数据版本及许可证，记录访问或下载日期。
2. 使用提供方客户端或脚本下载，保留实际使用的命令、下载参数与执行结果。
3. 核对文件大小和 SHA-256；提供方公布校验值时，与其逐项比较，记录校验结果。
4. 整理文件时保留原始数据；清洗、筛选或格式转换应另存结果，并记录输入、处理脚本与输出的对应关系。

下载后的受支持文件可以在[生命科学预览](./life-science-preview.md)中查看；[Biology Room](./biology-room.md)可组织其支持的序列、结构和基因组资产。预览和资产组织不能替代数据下载、完整性校验或分析。数据获取、清洗与科学结论各自需要真实执行和来源记录，见[证据与可复现性](./evidence-and-reproducibility.md)。
