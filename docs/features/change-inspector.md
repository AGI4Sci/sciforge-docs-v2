# 变更检查（Change Inspector）

Change Inspector 帮你检查当前任务修改了哪些文件，以及每个文件改了什么。安装并启用插件后，可以直接让 AI助手列出改动，再逐项核对。

## 使用方式

从可信来源安装兼容包，启用插件并授予所需权限，参见[扩展中心](./extensions.md)及[版本与兼容性](../reference/version-and-compatibility.md)。在已产生文件改动的当前会话中，可以这样要求助手：

> 检查这次任务修改了哪些文件，逐项说明改动。如果内容太长，请分批展示，并告诉我还有哪些内容没显示。

先看文件清单，确认改动范围符合任务要求，再检查重要文件的具体内容。如果还有遗漏的内容，让助手继续分批展示；需要核对完整内容时，直接分批读取实际文件。

## 使用提示

- 检查结果只包含当前会话已经记录的文件改动，不包含同一工作区其他会话的记录。
- 手动编辑或其他工具产生的改动可能没有出现在记录中。需要确认这些改动时，应检查实际文件，必要时对照 Git 状态。空列表不代表工作区从未被修改。
- 文件或改动较多时，展示内容可能不完整。先确认哪些内容尚未显示，再继续分批检查；不要仅凭部分差异重建整个文件。
- 审查期间如果又发生编辑，应刷新文件改动列表，重新核对受影响的文件。
- 停用插件或撤销权限后，需要重新启用或授权才能继续检查。

## 检查后的处理

变更检查只读取记录，不会修改文件、回滚或保存检查点，也不会发起网络请求。发现问题后，可以让助手修改对应文件，再重新检查。需要恢复工作区状态时，参见 [Git 检查点](./git-checkpoints.md)。
