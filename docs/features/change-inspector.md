# 变更检查（Change Inspector）

Change Inspector 读取 Agent 会话上报的文件变更，按文件汇总变更数量与状态，并渲染统一 diff。它解决“Agent 说改完了，但到底改了哪些文件、改了什么”的问题；它只读展示会话变更，不代替项目级 Git 状态，也不负责保存检查点。

## 打开方式

- 入口：顶部工具栏 **变更**；右侧面板标题同为 **变更**。
- 作用对象：当前会话中由 Agent 线程上报的文件变更。
- 前提：会话绑定工作区，且任务已经产生写入操作。

![SciForge 变更面板](/img/docs/guides/workspace-changes.jpg)
*变更面板按文件汇总一次会话的改动，并支持逐行查看差异。*

## 能做什么

| 你要完成的事 | 怎么做 | 产出 |
| --- | --- | --- |
| 看本次改了哪些文件 | 打开 **变更**，查看文件列表与变更数 | 会话级文件清单 |
| 只看某类状态 | 使用状态筛选：全部、已完成、运行中或失败 | 过滤后的变更列表 |
| 按文件名定位 | 在 **筛选变更文件** 中输入关键字 | 匹配的文件 |
| 核对逐行差异 | 选择文件查看 diff，需要时复制 diff | 统一差异视图 |
| 区分任务改动与原有状态 | 对照工作区文件与 Git 状态检查 | 人工审查结论 |

## 典型流程

1. 写入型任务结束后，从顶部工具栏打开 **变更**。
2. 先确认变更文件数量与范围是否符合预期。
3. 用状态或文件名筛选，定位关键文件和失败项。
4. 选择文件逐行核对新增、删除与修改，必要时复制 diff 讨论。
5. 发现问题时回到原会话引用具体文件修正，并独立检查项目级 Git 状态。

## 输入、输出与权限

- 读取：当前会话的变更观察、文件路径、任务状态与 diff 内容。
- 写入：无；面板不会修改工作区文件。
- 审批或外部影响：没有审批步骤，也不会发起外部请求。
- 不会做什么：不替代 Git 提交历史，不恢复或撤销改动，也不会因为关闭面板而停止宿主的会话记录。

## 已知限制

- 当前实现范围只覆盖会话上报的变更；空面板可能只是没有变更或没有上报，不代表任务一定没有写文件。
- 最多显示最新的 5,000 项变更，更早的变更不会出现在列表中。
- 运行中的任务可能继续产生变更，需要刷新或重新打开面板核对。
- 它提供的是会话视角，不是项目级历史 diff；Git 基线请使用 Git Checkpoints 或独立 Git 检查，跨会话汇总不属于本面板。
- 读取失败时面板会显示错误，需要重新加载后再判断变更结果。
