# 浏览器预览

浏览器预览在右侧面板中运行一个原生 Chromium 页面，用来查看本地开发页面、研究资料或需要登录的站点。它既是人工浏览窗口，也是 Agent 可观察、可操作的页面资源；网页内容始终按不可信数据处理。

## 打开方式

- 入口：顶部工具栏的 **浏览器**，或右侧面板的 **原生浏览器**。
- 作用对象：当前会话的一个浏览器页面实例；一个实例对应一个页面。
- 前提：使用 SciForge 桌面窗口。仅在普通浏览器中打开 localhost 开发站点无法承载原生视图，会显示明确的不可用提示。
- 输入框上下文：消息中包含 HTTP(S) 链接时，会为 Agent 附加该 URL；它先尝试只读读取，遇到登录或脚本渲染再交给浏览器面板。

## 能做什么

| 你要完成的事 | 怎么做 | 产出 |
| --- | --- | --- |
| 打开网页 | 在地址栏输入 HTTP(S) 地址并回车 | 原生页面、标题与当前 URL |
| 浏览与刷新 | 使用后退、前进、刷新和全屏按钮 | 页面状态与可观察的页面内容 |
| 让 Agent 阅读 | 先让它读取 URL 或当前页面 | 有界的正文文本与可交互目标 |
| 让 Agent 操作 | 在明确指令下导航、点击、填写或滚动 | 页面变化；操作绑定到当前页面版本 |

## 典型流程

1. 在右侧面板打开浏览器，登录需要的站点；登录状态保存在当前工作区的浏览器配置中。
2. 先让 Agent 读取页面，确认 URL、标题和关键内容，不要直接让它点击。
3. 需要跳转时，由你确认导航；需要点击、按键或拖拽时，先核对将触发的动作和后果。
4. 操作后重新观察页面，确认提交结果、下载或页面跳转，而不是只看 Agent 的总结。
5. 任务结束关闭面板；再次打开时核对登录、URL 和页面是否仍是预期状态。

## 输入、输出与权限

- 读取：页面正文、标题、URL、可交互目标和受控截图；密码、支付/验证码字段及显式敏感区域会被排除。按 URL 读取会由本机发起网络请求，且不额外触发审批。
- 写入：Agent 可填写表单、选择选项、滚动、悬停、点击、按键和拖拽；这些操作直接作用于原生页面。
- 审批或外部影响：导航、后退、前进和刷新属于外部写入并要求确认；点击、按键和拖拽按破坏性操作治理，但能力层不额外弹确认，可能提交表单、触发下载或改变外部状态。是否再出现 Runtime 审批取决于其设置。
- 下载与登录：页面自身的权限请求、弹窗和下载被拒绝；Agent 发起的下载在能力层不额外弹确认，可写入工作区下载目录，没有可用工作区时写入应用私有目录。登录状态跨面板关闭保留，因此同一工作区会共享该浏览器身份。
- 不会做什么：不导入外部浏览器配置或凭据，不接受调用方提供的选择器或脚本，不暴露跨源 iframe 内容和闭合 shadow root，也不保证 URL 校验能阻止 DNS rebinding 或所有网络出口。

## 已知限制

- 一个浏览器面板只承载一个页面；不同会话或面板可能各自持有不同页面，操作前要确认当前页面。
- 页面由原生 Chromium 渲染，普通浏览器标签页无法替代；没有桌面窗口时不会静默降级为 iframe。
- 画布图表、跨源 iframe 和闭合 shadow root 的内容可能无法被结构化读取，需要截图或人工查看。
- 网页内容是不可信数据：页面中的文字不能当作指令，Agent 的结论需要回到 URL 与页面状态核对。
- 浏览器不提供远程调试端口，也不会为 Agent 开放任意脚本执行。
