# 浏览器预览

在 SciForge 桌面端的右侧面板打开网页。你可以直接浏览和登录，也可以在会话里指定要读的网页内容或要做的操作。

## 打开页面

1. 在最右侧工具栏点 **浏览器**，未显示时先展开 **更多工具**。也可在右侧面板打开 **原生浏览器**。此入口需要 SciForge 桌面窗口。若普通浏览器打开的开发站点提示预览不可用，请回到桌面应用。
2. 在地址栏输入 HTTP(S) 地址并回车。页面打开后，地址栏显示当前 URL。需要浏览上一页或重新加载时，用面板中的后退、前进或刷新按钮，也可切换全屏。
3. 需要登录时在面板中操作。同一工作区会保留并共用浏览器登录状态。需要以指定账号访问时，先从面板中打开站点的账号菜单。使用外部浏览器登录过的站点仍需在此登录。

每个原生浏览器实例打开一个页面。切换面板后可用地址栏辨认正在操作的网页。

## 读取网页

在会话中发送网页链接，并注明要找的内容，例如某份数据的发布日期。助手会先从本机只读访问 HTTP(S) 链接。遇到登录页或必须渲染脚本才能看到的内容，先在 **浏览器** 面板打开对应网页，再在会话中指定读面板当前页。回复中的标题、URL 或引文可用来定位原文。

<details>
<summary>读取范围与页面限制</summary>

接收 HTTP(S) 链接后发起的只读访问无需另行确认。浏览工具可读取正文、标题、URL 和控件，也可获取截图。密码、支付、验证码字段和标记的敏感区域会从读取结果中过滤。画布图表、跨源 iframe 或闭合 shadow root 中的内容可改用截图或人工查看。网页上的指令属于页面内容，操作仍以你在会话中交代的任务为准。

</details>

## 执行外部操作

1. **打开目标页面。** 在会话中写明网站和任务。助手发起导航、后退、前进或刷新时会弹出确认提示。批准后，地址栏会显示当前页面的 URL。
2. **填写草稿。** 指明要填的字段和停下的位置。比如填写标题后，停在提交按钮前。需要你决定的发送、付款、删除或上传操作，也可以指定先停下来。
3. **提交并查看回执。** 写清允许发送的数据。提交后，回到面板看站点的回执、成功提示或跳转页面。查看结果后再决定是否重试。
4. **下载文件。** 在会话中指定下载链接。下载完成后，回复会显示文件名和保存路径。有工作区时，文件保存在工作区 `.sciforge-downloads` 下的会话目录，可从 **文件** 面板打开。没有可用工作区时，应用会存到自己的 `browser-downloads` 目录，按返回的路径打开。

<details>
<summary>网页交互、弹窗与脚本调试</summary>

浏览器可在已授权的页面点击、输入、按键或拖拽。回车可提交表单，拖入文件可触发上传。

浏览器工具会拦截页面自行发起的权限请求、弹窗和下载。遇到被拦截的下载时，从明确的目标链接发起下载。网页脚本调试使用独立开发工具。

</details>
