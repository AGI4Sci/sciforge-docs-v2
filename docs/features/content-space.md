# 内容空间

内容空间用于查看已连接的笔记服务并选择笔记本。当前支持思源笔记，只列出思源中已打开、未关闭的笔记本。笔记内容仍保存在原来的思源服务中。

## 打开与选择笔记本

1. 先按照[思源笔记](./siyuan.md)页面的说明连接自己的思源服务。
2. 打开右侧面板的 **内容空间**；协作整页中的 **共享文件** 也提供这一入口。
3. 选择已连接的思源服务，再选择列表中的笔记本。找不到目标时，先到思源中确认该笔记本已打开。
4. 需要阅读、编辑或搜索文档时，打开 **思源笔记** 页面，或让 Agent 使用思源搜索、读取和写入工具。

## 使用提示

- 当前内容空间提供笔记本选择，不能在这里浏览、编辑思源文档或上传、下载文件。
- **共享文件** 入口目前也没有直接上传按钮。选择笔记本不会把本地文件传入思源。
- 连接失效时先检查思源服务地址与连接状态，再重新连接。
- 文档编辑和 Agent 写入会影响已连接的思源服务；操作前确认目标笔记本与文档。
