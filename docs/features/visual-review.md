# 查看与修改图件

使用独立的 [Scientific Figures](./scientific-plotting.md) 插件，从数据和 Python + Matplotlib 代码生成图件。先安装兼容插件并准备所需环境，再用文字说明绘图或修改要求。

1. 选择工作区中的数据和代码，说明需要修改的内容，例如“保留数据，把线改为蓝色，标题缩短”。只有图片时不能恢复精确数据。
2. 让 Agent 保存新的代码版本并实际运行，检查运行状态和输出，成功后生成候选图。
3. 在 **当前图 / 修改后** 中比较当前版本与候选；有多个候选时，从 **候选** 下拉框切换。
4. 满意后点击 **申请接受**，核对对象并完成宿主正式审批，当前图才会更新；需要继续修改时保留当前图，再说明要求。

插件保存不可变的代码、输入、运行与图片版本；接受候选会更新当前图，原图和运行记录继续保留。图件变化后，候选可能需要重新生成。它不提供图上框选、箭头或图钉批注，也不自动向产物版本或证据关系登记记录。

对具体文字或已注册任务视图留下意见，可使用独立的[锚定批注](./anchored-comments.md)。截图能力依赖宿主授权与捕获服务；保存批注不代表图片已经修改、候选已接受或产物版本已注册。跨产物的来源和交付记录见[证据与可复现性](./evidence-and-reproducibility.md)。
