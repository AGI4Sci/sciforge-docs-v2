# 科研档案（Research Dossier）

科研档案把研究摘要、来源、关键产物、版本和限制放在一起，方便回顾与交付。打开一条科研记录后，先阅读结果和需要关注的限制，再按需查看历史版本；过程记录来自 [Research Checkpoints](./research-checkpoints.md)，证据关系见 [Evidence DAG](./evidence-dag.md)。

## 打开方式

- 入口：右侧工具栏（未显示时展开 **更多工具**）的 **科研**；右侧面板标题同为 **科研**；也可以从会话结果卡片点击 **打开科研档案**。
- 查看历史时，打开指定的产物版本或科研记录，先确认正在阅读的是哪条记录。
- 前提：会话绑定工作区；保存研究检查点或产物版本后，可以查看对应的详细记录。

![SciForge 科研档案面板](/img/docs/guides/research-dossier.jpg)
*科研档案把研究叙事、版本位置、可信度摘要与需要关注的限制放在一起。*

## 阅读和核对记录

1. 完成一轮研究，在结果卡片点击 **打开科研档案**。
2. 确认选中的研究记录及版本，阅读概览、研究来源、声明文件和关键产物。
3. 查看 **需要关注的限制** 与 **溯源断点**，逐项检查缺失来源、未验证结果和复现条件。
4. 需要回顾历史时，在 **版本** 区加载更早版本，使用 **比较精确版本** 检查差异。
5. 需要使用历史结果时，选择 **恢复为新版本** 并确认，随后核对恢复结果及实际文件。原有历史会保留。

选中的记录缺失或校验不一致时，档案会给出提示。请核对记录和相关文件，确认问题解决后再用于交付。

## 预览与交付

使用 **打开已校验预览** 查看选定内容，或使用 **导出 Bundle V2** 打包交付。导出会写出工作区文件，并请求确认；请检查所有必需的相关版本和文件是否齐全、是否允许访问与导出，并交代尚未验证的内容。分享前也应检查包内是否包含敏感数据。

恢复和旧会话导入需要按提示确认。导入的旧会话会持续标记为历史记录不完整，并提示缺失的溯源信息。在这里也可以开启或停止自动记录，具体行为见[研究检查点](./research-checkpoints.md)。

## 使用提示

- 展示内容取决于任务已保存的检查点、产物版本和证据。尚无记录时，需要先完成并保存一轮任务。
- 某部分记录暂时无法读取时，对应内容可能不可用，其余已校验内容仍可阅读。
- 空白或不适用的计算、证据、审查区块会被省略。需要查看完整证据关系时，打开 Evidence DAG。
- 档案中的摘要与引用需要结合实际文件核对，尤其是在相关文件被修改、移动或删除之后。
