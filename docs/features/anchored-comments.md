# 锚定批注（Anchored Comments）

在研究记录中选中一段文字，可以为它留下问题、修改建议或审查意见。批注保留选中的文字及其所属研究记录条目，方便之后回查。

## 添加批注

本页使用 **0.2.3** 的操作。开始前启用兼容版本，并确保当前工作区允许保存批注。到 [扩展中心](./extensions.md) 查看安装入口。

1. 打开要批注的工作区，并选中包含原文的会话。
2. 打开**研究记录**，在同一个条目内拖选一段文字。
3. 点 **添加批注**。面板会带入选中的原文和所属研究记录条目。
4. 写下意见，点 **保存批注**。看到「批注已保存」后，可在已有批注列表中查看这条意见。

**讨论选区**会打开带有该段文字的聊天草稿。如果要保存成批注，请使用**添加批注**。面板已有未保存内容时，新选区会提示 **保留当前草稿** 或 **放弃旧正文并替换选区**。

例如，在研究记录中选中「缺失值已填为 0」，点击 **添加批注**，写下「请核对空值是否表示未测量」，保存后可在会话中查询该条批注。结果应包含选中的原文和这条意见。

## 查看、修改与删除

点面板中的 **刷新已有批注** 可查看当前工作区保存的批注（面板最多展示前 200 条），也可以在会话中让助手列出、查看或更新批注。当前面板主要用于新建批注；需要修改已有批注时，可在会话中告诉助手要更新哪条批注及修改内容。

删除批注需要确认。批注保存在工作区中，不会改动被批注的源文件。切换项目后，请重新选择要批注的内容。

## 截图与反馈

要为批注保存当前应用视图，请在支持截图且已授权的客户端单独截图。先把账户、令牌或其他敏感信息移出画面。

向外部提交反馈也需要单独确认。如果反馈服务没有配置，就只能在本地保存和讨论。

## 使用提示

- 原文变动后，重新核对引文与位置。
- 批注属于当前工作区。分享项目之前，检查批注和截图中是否含不想共享的内容。
- 「添加批注」未出现时，先确认插件已启用，再在当前会话的同一条研究记录内重新选中文字。
