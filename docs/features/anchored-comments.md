# 锚定批注（Anchored Comments）

在研究记录中选中一段文字，可以为它留下问题、修改建议或审查意见。批注保留原文和位置，方便之后回查。

## 添加批注

1. 在[扩展与市场](./extensions.md)安装并启用兼容的 Anchored Comments 插件。
2. 打开**研究记录**，在同一个条目内拖选一段文字。
3. 点击**添加批注**，检查面板中的原文和目标。
4. 写下意见，点击 **Save** 保存。

**讨论选区**会打开带有该段文字的聊天草稿。如果要保存成批注，请使用**添加批注**。面板已有未保存内容时，新选区会提示保留或替换草稿。

## 查看、修改与删除

可让 Agent 列出或读取当前工作区的批注，也可以让它更新已有线程。当前面板主要用于新建批注，编辑已有内容请使用插件工具。

删除批注需要确认。批注保存在工作区中，不会改动被批注的源文件。切换项目后，请重新选择要批注的内容。

## 截图与反馈

截图是单独操作，保存文字不会自动截图。只有宿主提供了对应功能并允许捕获时，插件才能保存当前应用视图的截图；捕获前应检查是否含账户、令牌或其他敏感信息。

向外部提交反馈也需要单独确认。如果反馈服务没有配置，就只能在本地保存和讨论。

## 使用提示

- 原文变动后，重新核对引文与位置。
- 批注属于当前工作区。分享项目之前，检查批注和截图中是否含不想共享的内容。
- 当前插件版本为 **0.2.1**。安装要求与版本说明见[版本与兼容性](../reference/version-and-compatibility.md)。
